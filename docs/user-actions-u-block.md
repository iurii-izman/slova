# Блок U — что осталось сделать пользователю (пошагово)

Этот список покрывает `U1..U10` из `transcriber-autopilot-development-plan.md`.

## Уже проверено AI

- FFmpeg установлен и доступен в PATH.
- FFprobe установлен и запускается.
- В сборке FFmpeg есть `arnndn` и `libopus`.
- `cb.rnnn` в проекте **не найден** (нужно добавить вручную).

## Шаг 1 — U1. Локальное окружение

Проверь версии в терминале:

- `rustc --version`
- `cargo --version`
- `node --version`
- `npm --version`

Если Tauri ругается на toolchain/SDK, установи:

- WebView2 Runtime (если отсутствует)
- Visual Studio Build Tools + Windows SDK

## Шаг 2 — U2. Groq API key

1. Зарегистрируйся на `https://console.groq.com`.
2. Создай ключ на `https://console.groq.com/keys`.
3. Запусти Slova и открой Settings.
4. Вставь ключ и нажми `Save API Key`.

Важно:

- не отправляй ключ в чат;
- не коммить ключ в git.

## Шаг 3 — U3. FFmpeg/ffprobe policy

Раз ты планируешь публичный релиз, зафиксируй источник бинарников и лицензию в документации релиза.

Минимум что должно быть подтверждено:

- `ffmpeg -filters` содержит `arnndn`;
- `ffmpeg -encoders` содержит `libopus`;
- `ffprobe -version` отрабатывает.

## Шаг 4 — U4. Добавить rnnoise модель

Нужно вручную положить `cb.rnnn` в:

- `resources/rnnoise-models/cb.rnnn`

Если модель не найдена, приложение всё равно работает, но шумоподавление хуже.

## Шаг 5 — U5. Подготовить тестовые видео

Сделай локальный набор (не коммить большие/приватные файлы):

1. `short-ru-20s.mp4` — 10–30 сек русской речи.
2. `no-audio.mp4` — видео без аудиодорожки.
3. `noisy-ru.mp4` — русская речь с фоновым шумом.
4. `кириллица и пробелы.mp4` — файл с русскими символами и пробелами в пути.
5. `long-30min.mp4` — длинный файл 30+ минут.

Где взять:

- Самозапись с телефона/OBS (лучший вариант для приватности и прав).
- Открытые CC0/royalty-free материалы с явной лицензией.

## Шаг 6 — U6. Реальная проверка Groq (live smoke test)

1. Ввести API key в Settings.
2. Добавить `short-ru-20s.mp4`.
3. Проверить, что создан `.txt` рядом с исходником.
4. Проверить качество русского текста.
5. Проверить 3-5 файлов батчем.
6. По возможности спровоцировать retry/rate-limit.

## Шаг 7 — U7. UX-решения (уже зафиксированы)

Смотри `docs/owner-decisions-v0.1.md`.

## Шаг 8 — U8. Публикация и подпись

Для первого публичного релиза (бюджетно):

1. Выпускай через GitHub Releases.
2. Подпись кода можно отложить, но в релиз-нотах предупреди про SmartScreen.
3. Не коммить приватные ключи/секреты.

## Шаг 9 — U9. Privacy / legal

Перед релизом:

1. Добавь `PRIVACY.md` (минимум: что уходит в Groq, что хранится локально).
2. Укажи в README, что аудио отправляется в облачный API.
3. Зафиксируй политику хранения транскриптов в SQLite.

## Шаг 10 — U10. Финальный acceptance на чистой Windows 11

Чеклист:

- Установка и запуск без API key.
- Ввод API key через Settings.
- Drag&drop 10-50 файлов.
- Cancel/Retry.
- Экспорт TXT/SRT/JSON.
- Перезапуск и восстановление истории.
- Понятная ошибка при отсутствии ffmpeg.
- Проверка кириллических путей.
- Проверка нестабильной сети.
