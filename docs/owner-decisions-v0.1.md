# Slova v0.1 — Owner decisions (approved)

## Принятые решения

1. **Название приложения:** `Slova`.
2. **Папка вывода по умолчанию:** рядом с исходным видео.
3. **Конфликт имени выходного файла:** `suffix` (безопасный вариант, не теряет данные).
4. **Postprocess (Llama) по умолчанию:** выключен.
5. **Tray mode в v0.1:** не включаем.
6. **Auto-update в v0.1:** не включаем (добавим после стабилизации релиза).
7. **Privacy-позиция:** разрешаем отправку аудио в Groq, но явно предупреждаем в UI.
8. **Privacy warning в UI:** включён (Settings содержит явный текст про отправку аудио в Groq).
9. **Кнопка “удалить историю и транскрипты” в MVP:** отложено до v0.2 (нужен отдельный UX и safety-confirmation).
10. **Privacy policy:** нужна, минимум как документ в репозитории до публичного релиза.
11. **Тип релиза:** публичный.
12. **Code signing в первом релизе:** отложен (допускаем SmartScreen warning для ранней версии).
13. **Хостинг релизов:** GitHub Releases (бесплатно).

## Почему такие дефолты

- `suffix` + вывод рядом с видео = минимальный риск потери данных и предсказуемое поведение.
- Postprocess выключен по умолчанию = ниже стоимость и меньше “магии” в тексте.
- Auto-update и signing отложены = быстрее выйти в публичный тех-preview.

- Добавить `PRIVACY.md`.

- Явно описать в README ограничения по unsigned build (если code signing отложен).
