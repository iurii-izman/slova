# Security Policy

## Supported Versions

We actively support the following versions with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it to us as follows:

1. **Do not** create a public issue on GitHub.
2. Email the details to [security@iurii-izman.dev](mailto:security@iurii-izman.dev) (replace with actual email if available).
3. Include:
   - A description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Any suggested fixes

We will acknowledge receipt within 48 hours and provide a more detailed response within 7 days indicating our next steps.

We kindly ask that you give us reasonable time to fix the issue before disclosing it publicly.

## Security Considerations

This application handles API keys and user data. Please ensure:
- API keys are stored securely using the OS keychain
- No sensitive data is logged or exposed
- Dependencies are kept up to date

Thank you for helping keep our project secure!
